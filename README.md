# All Calc

A static advanced web calculator with Algebra, Trigonometry, Calculus and Units tabs. Open index.html in a modern browser; it needs no package installation or build step.

The Calculus tab supports numerical derivatives, definite integrals, approximate two-sided limits and finite integer summation. Input a mathematical expression f(x) using x, pi, e, arithmetic operators, ^ for exponentiation, and functions such as sin(x), cos(x), sqrt(x), ln(x). The results are numerical approximations, not symbolic simplifications.

## Run tests

Install Node.js, then run:

    node tests/calculus.test.cjs
    node --check script.js
    node --check calculus.js
